# Plan Table

A browser-based drawing review tool. Lay out a whole drawing set on one screen, mark up sheets, pin comments, stamp a review status, compare revisions, and save the markups back into the PDFs.

- Runs entirely in the browser — files stay on your device, nothing is uploaded.
- Single self-contained file: `index.html`.
- Needs an internet connection to load the PDF engine and fonts.

## Use

Open `index.html` in a browser, or visit the GitHub Pages site if it's enabled for this repository.
